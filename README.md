# Pankaj Kumar — Developer Portfolio

A personal portfolio website showcasing my projects, technical skills, and work as a full-stack JavaScript developer.

> **Status:** Portfolio repository is being set up. The live application and screenshots will be added when the implementation is published.

## Tech Stack

- React
- Tailwind CSS
- JavaScript
- Responsive UI development

## Planned Sections

- **About** — background and development interests
- **Skills** — technologies and tools I use
- **Projects** — selected applications, architecture, and demos
- **Contact** — professional links and ways to connect

## Run Locally

Once the application source code has been added:

1. Clone this repository:
   ```bash
   git clone https://github.com/Pankaj12222674/portfolio.git
   cd portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
